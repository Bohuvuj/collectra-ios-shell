# Collectra CMS for iPhone (beta)

The iPhone shell of [Collectra CMS](https://singercms.bohuvuj.com). It only opens the live site in a full-screen app; there is no app code, data or key here. Every web update reaches it without a new build.

Each run of **Actions → iPhone beta** builds an **unsigned** `.ipa` and publishes it as the latest release. Install it from a computer with [Sideloadly](https://sideloadly.io) or [AltStore](https://altstore.io), signed with your own Apple ID (free; reinstall every 7 days). Push notifications are not available in this beta.

Download: <https://singercms.bohuvuj.com/download> → iPhone.
